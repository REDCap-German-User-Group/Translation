# Deutsche REDCap-Übersetzung

KI-assistierte (ChatGPT 5.5+) deutsche Übersetzung der REDCap Benutzeroberfläche, basierend auf dem GUG Ruleset.

## Download

Die verwendungsfertige Übersetzung wird für jede unterstützte REDCap-Version als `German_X.Y.Z.zip` veröffentlicht. Das Archiv enthält `German.ini` und eine kurze README-Datei.

**[German_X.Y.Z.zip aus dem aktuellen Release herunterladen](https://github.com/REDCap-German-User-Group/Translation/releases/latest)**

Verwenden Sie die Übersetzung, deren Versionsnummer Ihrer REDCap-Version entspricht. Die von GitHub zusätzlich angezeigten Downloads „Source code (zip)“ und „Source code (tar.gz)“ sind technisch bedingt und absichtlich leer.

## Übersetzungsworkflow

Die Übersetzungsregeln stehen in [Rules/German.md](Rules/German.md). Der automatisierte Ablauf zum Abrufen, Übersetzen und Veröffentlichen neuer Sprachstrings ist in [TRANSLATE.md](TRANSLATE.md) beschrieben.
